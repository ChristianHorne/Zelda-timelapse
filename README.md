# The Legend of Zelda – Time Lapse Animation

Frontend project inspired by *The Legend of Zelda*.
It consists of an animated time-lapse created using pure HTML, CSS, and JavaScript.

## 🚀 Technologies
- HTML5
- CSS3 (animations)
- JavaScript (DOM manipulation and timing)

## 🎮 Features
- Time-lapse style animation
- Design inspired by the Zelda universe
- No external libraries
